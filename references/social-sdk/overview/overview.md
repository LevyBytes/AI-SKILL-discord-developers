# Discord Social Sdk - Overview

> Discord Developers reference. Original prose; identifiers preserved verbatim.

(Figure: Discord Social SDK Hero Image) The Discord Social SDK embeds Discord-backed social capabilities in a game. For the feature set at a higher level, see the [Social Layer for Games](https://docs.discord.com/developers/platform/social-layer) platform page. Begin integrating the SDK with the getting started guides, design guidelines, and code samples.
