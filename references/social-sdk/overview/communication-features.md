### Communication Features

 Text and voice communication features are available through Discord Social SDK, but rate limits apply. Current communication-feature limits are documented in [Communication Features: Rate Limits](https://docs.discord.com/developers/discord-social-sdk/core-concepts/communication-features#rate-limits). Access details for these features are covered in [Core Concepts: Communication Features](https://docs.discord.com/developers/discord-social-sdk/core-concepts/communication-features).
