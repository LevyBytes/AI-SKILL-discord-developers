### Detailed Feature Descriptions

 Use this chart when announcement copy needs to call out individual features and player benefits. Players usually do not need the exact "Feature Name", but the descriptions and example use cases can help explain value.
| Feature Name | Short Description | Use Cases |
| --- | --- | --- |
| **Rich Presence** | Displays on Discord the games that players are currently in. | Seeing friends' in-game activity so you can tell whether they may want to play together; joining from a friend's profile, similar to game invites. |
| **Unified Friends List** | Lets players open their Discord friends list inside the game, including friend tiers. | Sending game invites to friends from within the game; seeing which friends are playing and which online friends might join; avoiding the need to rebuild a social friends list in each new game. |
| **Deeplink Game Invites** | Lets users send invites that deep-link into particular game instances or game areas. | Inviting users into specific game instances or challenges. |
| **Flexible Account Requirements** | Users may link a Discord account for deeper features such as Unified Friends List and Rich Presence, while still being able to use in-game social features without linking by using a "provisional account." | Account linking: Discord-based automatic sign-in, or connecting a Discord account with a game account, enabling the full Discord integration. Provisional accounts: Provisional accounts allow Discord voice and text chat in connected games without first creating a Discord account. |
| **Cross-Platform Messaging** | Enables smooth communication in-game and through Discord, including for players without a Discord account. | DMing friends while they are in-game or outside the game; receiving messages while not playing; in-game text chat for guilds, matches, lobbies, and similar spaces. |
| **Linked Channels** | Lets players connect an in-game group chat to Discord channels, creating persistent group chat spaces. | Mirroring in-game guild or group chat into the guild's or group's Discord server; reducing isolation when some members are online in-game and others are active elsewhere. |
| **Discord Voice Chat** | Adds Discord-powered high quality voice chat directly in the game. | In-game voice chat for guilds, matches, lobbies, and similar group contexts. |
