### ISO8601 Date/Time

 Most Date/Time values in Discord models use the [ISO8601 format](https://www.loc.gov/standards/datetime/iso-tc154-wg5_n0038_iso_wd_8601-1_2016-02-16.pdf). Documentation tables refer to this type as `ISO8601`.
