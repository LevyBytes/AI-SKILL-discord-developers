### Webhooks

#### Webhooks Update

 Emitted after a guild channel webhook is created, modified, or deleted.

###### Webhooks Update Event Fields

| Field | Type | Description |
| --- | --- | --- |
| guild_id | snowflake | ID of the guild |
| channel_id | snowflake | ID of the channel |
