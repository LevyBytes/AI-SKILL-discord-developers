# Legacy Mention Behavior Deprecation

Date: 2020-05-11
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4209) · [Year index](INDEX.md)

<a id="source-legacy-mention-behavior-deprecation"></a>


Legacy bot mention behavior has been removed, and mention control should now be handled through the [Allowed Mentions](https://docs.discord.com/developers/resources/message#allowed-mentions-object) API.
