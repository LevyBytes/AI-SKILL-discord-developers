# GameSDK Version 2.5.5

Date: 2019-11-14
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4298) · [Year index](INDEX.md)

<a id="source-gamesdk-version-255"></a>


GameSDK updates shipped with Linux support and Unity IL2CPP backend support. The release also fixed an issue in [`SetUserAchievement()`](https://github.com/discord/discord-api-docs/blob/legacy-gamesdk/docs/game_sdk/Achievements.md#setuserachievement). Download the latest version from the top of [Getting Started](https://docs.discord.com/developers/developer-tools/game-sdk#step-1-get-the-sdk). For GameSDK help or bug reports, join the [official Discord](https://discord.gg/discord-developers).
