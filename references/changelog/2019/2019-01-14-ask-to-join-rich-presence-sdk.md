# Ask to Join & Rich Presence SDK

Date: 2019-01-14
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4372) · [Year index](INDEX.md)

<a id="source-ask-to-join--rich-presence-sdk"></a>


Ask to Join can now be used without approval or whitelisting. You may build in-game UI, while Discord overlay also handles Ask to Join requests. Rich Presence SDK docs gained a few additions, including the formerly undocumented `UpdateHandlers()` function.
