Documentation was expanded for the [Server Nitro Boosting](https://support.discord.com/hc/en-us/articles/360028038352-Server-Boosting) experiment. The update adds [message types](https://docs.discord.com/developers/resources/message#message-object-message-types) and [new fields on guilds](https://docs.discord.com/developers/resources/guild#guild-object-premium-tier). This feature remains experimental, so the fields can change.
