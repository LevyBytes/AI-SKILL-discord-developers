# Deprecation of Discord-RPC Rich Presence SDK

Date: 2019-04-29
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4354) · [Year index](INDEX.md)

<a id="source-deprecation-of-discord-rpc-rich-presence-sdk"></a>


[Discord-RPC](https://github.com/discord/discord-rpc) Rich Presence is deprecated in favor of Discord's GameSDK. To use Rich Presence, read the [SDK Starter Guide](https://docs.discord.com/developers/developer-tools/game-sdk#getting-started) and review the [Activity Manager](https://docs.discord.com/developers/developer-tools/game-sdk#activities) functions.
