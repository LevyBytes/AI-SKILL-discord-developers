# Additional Team Information

Date: 2019-06-19
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4336) · [Year index](INDEX.md)

<a id="source-additional-team-information"></a>


More Teams information was added to the API and docs. The [Teams](https://docs.discord.com/developers/topics/teams) page now describes team and team member objects. [Get Current Application Information](https://docs.discord.com/developers/topics/oauth2#get-current-bot-application-information) now returns a `team` object for team-owned applications, and the application docs now include missing fields for games sold on Discord.
