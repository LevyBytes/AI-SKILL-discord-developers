# New GUILD_MEDIA channel type

Date: 2023-08-01
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3240) · [Year index](INDEX.md)

<a id="source-new-guild_media-channel-type"></a>


- Added the [`GUILD_MEDIA` (16) channel type](https://docs.discord.com/developers/resources/channel#channel-object-channel-types). `GUILD_MEDIA` channels support only threads, similar to `GUILD_FORUM` channels.
See the [media channel topic](https://docs.discord.com/developers/topics/threads#media-channels) for APIs and technical details, or the [media channel Help Center Article](https://creator-support.discord.com/hc/en-us/articles/14346342766743) for feature information.
