# Public Preview of OpenAPI 3.1 Specification

Date: 2023-08-02
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3225) · [Year index](INDEX.md)

<a id="source-public-preview-of-openapi-31-specification"></a>


Discord is introducing an [OpenAPI 3.1 spec](https://github.com/discord/discord-api-spec) in public preview to make HTTP API development easier and more reliable. Unlike manually reviewed developer documentation, the OpenAPI spec is generated from source code and captures more Discord API detail. The public preview may break without advance notice and should not be used in production. If something looks wrong or improvable, [open an issue](https://github.com/discord/discord-api-spec/issues). The public spec is in the [`discord-api-spec` repository on GitHub](https://github.com/discord/discord-api-spec).
