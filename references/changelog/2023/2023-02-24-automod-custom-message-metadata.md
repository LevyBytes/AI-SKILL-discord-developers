# Add Auto Moderation custom_message Action Metadata Field

Date: 2023-02-24
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3329) · [Year index](INDEX.md)

<a id="source-add-auto-moderation-custom_message-action-metadata-field"></a>


Added `custom_message` [action metadata](https://docs.discord.com/developers/resources/auto-moderation#auto-moderation-action-object-action-metadata) for the `BLOCK_MESSAGE` [action type](https://docs.discord.com/developers/resources/auto-moderation#auto-moderation-action-object-action-types)). Each Auto Moderation rule can now define a custom string shown to members when the rule blocks their message. Use it to explain the block and help members understand server rules and guidelines.
