# Team Member Roles

Date: 2023-08-23
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3196) · [Year index](INDEX.md)

<a id="source-team-member-roles"></a>


Teams can now invite or configure members with roles other than admin. A team member can be owner, admin, developer, or read-only; see [role types](https://docs.discord.com/developers/topics/teams#team-member-roles-team-member-role-types). The team member object now includes [`role` field](https://docs.discord.com/developers/topics/teams#data-models-team-member-object), a string for the member's current role. See updated [Teams documentation](https://docs.discord.com/developers/topics/teams#team-member-roles).
