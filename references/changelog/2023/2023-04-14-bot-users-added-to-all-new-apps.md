# Bot users added to all new apps

Date: 2023-04-14
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3309) · [Year index](INDEX.md)

<a id="source-bot-users-added-to-all-new-apps"></a>


Starting today, [bot users](https://docs.discord.com/developers/topics/oauth2#bot-vs-user-accounts) are added to every newly created app. Bot user settings and configuration remain on the **Bot** page in the [app's settings](https://discord.com/developers/applications). If an app does not need or want a bot user, do not include the [`bot` scope](https://docs.discord.com/developers/topics/oauth2#shared-resources-oauth2-scopes) during installation.
