# Slash Command Mentions

Date: 2022-08-22
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3690) · [Year index](INDEX.md)

<a id="source-slash-command-mentions"></a>


[Slash Command mentions](https://docs.discord.com/developers/reference#message-formatting) are rolling out across Discord clients this week; on Android, they are limited to the [React Native client](https://discord.com/blog/android-react-native-framework-update). Clicking a Slash Command mention fills the user's message input with the command. Slash Command mentions use `</NAME:COMMAND_ID>`, with `</NAME SUBCOMMAND:ID>` and `</NAME SUBCOMMAND_GROUP SUBCOMMAND:ID>` available for subcommands and subcommand groups.
