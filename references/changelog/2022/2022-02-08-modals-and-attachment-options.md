# Interaction Modals and Application Command Attachment Option Type

Date: 2022-02-08

<a id="source-interaction-modals-and-application-command-attachment-option-type"></a>


Interaction modals are available, letting applications request more detailed input from users. See [the modal docs](https://docs.discord.com/developers/interactions/receiving-and-responding#interaction-response-object-modal). Application Commands can now include an attachment option type; see [the option type table](https://docs.discord.com/developers/interactions/application-commands#application-command-object-application-command-option-type).
