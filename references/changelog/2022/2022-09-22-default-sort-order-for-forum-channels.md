# Default Sort Order for Forum Channels

Date: 2022-09-22
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3629) · [Year index](INDEX.md)

<a id="source-default-sort-order-for-forum-channels"></a>


`default_sort_order` is an optional [channel object](https://docs.discord.com/developers/resources/channel) field that controls the default sorting of threads in a [forum channel](https://docs.discord.com/developers/topics/threads#forums). Changing `default_sort_order` requires `MANAGE_CHANNELS`. If unset, `default_sort_order` is `null`.
