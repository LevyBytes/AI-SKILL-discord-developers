# Forum Channels

Date: 2022-04-06
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3867) · [Year index](INDEX.md)

<a id="source-forum-channels"></a>


Discord added `GUILD_FORUM` (15), a new unreleased channel type. A `GUILD_FORUM` channel is similar to `GUILD_TEXT` from the API perspective, except it only permits thread creation and does not accept direct messages. See the [forums topic](https://docs.discord.com/developers/topics/threads#forums) for more information.
