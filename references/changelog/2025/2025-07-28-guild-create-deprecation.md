# Guild Create Deprecation

Date: 2025-07-28
Categories: HTTP API
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L1923) · [Year index](INDEX.md)

<a id="source-guild-create-deprecation"></a>




Apps can no longer create guilds. The endpoint documentation has been removed, and the endpoints are no longer present in the OpenAPI specification. See the [earlier changelog entry](https://docs.discord.com/developers/change-log#deprecating-guild-creation-by-apps) for details.
