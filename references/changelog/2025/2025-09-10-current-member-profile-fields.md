# Banner, avatar, and bio can be set on modify current member

Date: 2025-09-10
Categories: HTTP API
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L1583) · [Year index](INDEX.md)

<a id="source-banner-avatar-and-bio-can-be-set-on-modify-current-member"></a>


Starting September 10, 2025, bots can set the `banner`, `avatar`, and `bio` fields through the [modify current member](https://docs.discord.com/developers/resources/guild#modify-current-member) route.
