# Breaking Change: API & Gateway Below v6 Discontinued

Date: 2017-10-16
Categories: Breaking Change
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4470) · [Year index](INDEX.md)

<a id="source-breaking-change-api--gateway-below-v6-discontinued"></a>


[API](https://docs.discord.com/developers/reference#api-versioning) and Gateway versions earlier than v6 are discontinued after prior deprecation. Version 6 is now the default for both API and Gateway. Requests using versions below 6 return errors.
