# New Feature: Rich Presence

Date: 2017-11-09
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4455) · [Year index](INDEX.md)

<a id="source-new-feature-rich-presence"></a>


Rich Presence is live for all developers. It lets developers integrate games with Discord in several new ways, including:
- Showing richer details about a user's current game on their profile
- Letting users send chat invites to join a party or spectate a game
- Showing `Spectate` and `Ask to Join` buttons on user profiles
For details, see the [Rich Presence site](https://discord.com/rich-presence). To begin development, [read the docs](https://docs.discord.com/developers/rich-presence/overview).
