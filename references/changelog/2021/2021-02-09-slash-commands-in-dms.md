# Slash Commands in DMs

Date: 2021-02-09
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4081) · [Year index](INDEX.md)

<a id="source-slash-commands-in-dms"></a>


Slash Commands now work in DMs with bots. To support DM command context, some [Interaction object](https://docs.discord.com/developers/interactions/receiving-and-responding#interaction-object-interaction-structure) fields became optional. The newly optional fields do not change Slash Command behavior in guilds.
