# Select Menu Components

Date: 2021-06-30
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L3985) · [Year index](INDEX.md)

<a id="source-select-menu-components"></a>


Select Menus are part of the components API. They let apps present one or many UI-based choices to users. Select menus work like other [message components](https://docs.discord.com/developers/components/overview); see the [documentation](https://docs.discord.com/developers/components/reference#string-select).
