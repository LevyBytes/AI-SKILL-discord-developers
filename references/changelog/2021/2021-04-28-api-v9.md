# API v9

Date: 2021-04-28
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L4021) · [Year index](INDEX.md)

<a id="source-api-v9"></a>


API v9 is available. It includes support for [threads](https://docs.discord.com/developers/topics/threads), an upcoming feature. Older API versions will not receive Gateway Events for threads, so updating is important. The [migration guide](https://docs.discord.com/developers/topics/threads) is available to simplify the upgrade. This documentation is being released early so bots have at least two months to upgrade before threads launch. API v9 also removes `/channels/:id/messages/:id/suppress-embeds`.
