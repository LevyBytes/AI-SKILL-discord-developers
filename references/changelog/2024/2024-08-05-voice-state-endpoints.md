# Voice State Endpoints

Date: 2024-08-05
Categories: Voice, HTTP API
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L2731) · [Year index](INDEX.md)

<a id="source-voice-state-endpoints"></a>


Voice states are now available through the HTTP API. Apps can call [Get Current User Voice State](https://docs.discord.com/developers/resources/voice#get-current-user-voice-state) and [Get User Voice State](https://docs.discord.com/developers/resources/voice#get-user-voice-state) to fetch a user's voice state without using a Gateway connection.
