# Guild Member Banners

Date: 2024-07-16
[Official source](https://github.com/discord/discord-api-docs/blob/37148620d2324292b76047541d5f8331f81ea77a/developers/change-log.mdx#L2792) · [Year index](INDEX.md)

<a id="source-guild-member-banners"></a>


Apps can access guild member profile banners through the API and Gateway. The [guild member object](https://docs.discord.com/developers/resources/guild#guild-member-object) now includes a `banner` field that can be used to build the [guild member banner URL](https://docs.discord.com/developers/reference#image-formatting).
